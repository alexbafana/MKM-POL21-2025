# Participant task sheet

For each assigned case and method, using only the supplied source packet:

1. Identify stakeholders, goals, governance boundaries, and material authority.
2. Select and justify incentive, governance, and token-policy choices.
3. Identify material concentration risks and interactions over time.
4. Specify risk responses, remaining exposure, and how relevant changes would be reviewed.
5. Express one accepted design chain in downstream DAO-model specifications, or identify unsupported information explicitly.

Submit your records and models, a list of unavailable facts, and explanations of choices. Mark assumptions separately. Stop at the facilitator's pre-specified session limit; unfinished tasks remain results. Ask for clarification when necessary; each request will be recorded. Do not infer that more records necessarily means better design.

Debrief: Which steps were unclear? What useful information did the method expose? What did it miss? Where did it add unnecessary work? Which conclusions would change with additional evidence?

Facilitator preparation: freeze matched case packets before recruitment, vary order, document time limits and any pilot revisions, and keep pilot participants separate from the reported sample. The present package supplies Currynomics source records; additional matched vignettes require documented source packets before this comparative study is ready to run.
