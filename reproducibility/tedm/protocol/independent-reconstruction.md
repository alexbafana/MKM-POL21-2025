# Independent engineering reconstruction protocol

Status: planned; no independent reconstruction has been conducted in this package.

Freeze and record a source-package commit before recruitment. Give the independent modeler the case record, populated TEDM records, target schema versions, and task instructions; withhold the author-built models until the first reconstruction is submitted. Record relevant experience, prior involvement, assistance, task time, and deviations. Obtain applicable ethics approval and informed consent before collecting participant data.

Task: reconstruct the CG4 → IN3/AR3/TP4 → CP2 → M1/M6 → ER4 chain into DAO-ML and DAOMod ERD, preserving assumptions, treatment, residual risk, monitoring, and explicit representation gaps. Deliver semantic models and source-to-destination links. Visual notation and layout receive a separate expert review.

Before the session, two assessors must freeze a rubric covering material authority, mechanism semantics, source/destination coverage, contradictions, monitoring preservation, and information loss. Compare the submitted reconstruction to the rubric and then to the author draft. Report disagreements, failures, assistance, and corrections. A successful script run is not an independent reconstruction result.

## Required deliverables before claiming completed evaluation

- Populated records.csv and links.csv with evidence locators and status.
- Target schemas retrieved at the pinned commits and recorded validation logs.
- Independent model files and submission provenance.
- Completed rubric, discrepancies, adjudication, and revision log.
- Fixed release/commit citation; archival DOI when available.
