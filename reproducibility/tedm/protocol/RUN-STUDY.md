# Minimal coordinator workflow

1. Ask a qualified semantic reviewer to complete authority-decisions.csv, rights-completeness.csv, and the one model correction decision. The proposed entries are prefilled; reviewer edits and reasons supply the evidence. Independently check requirement-review.csv.
2. Two assessors review/freeze scoring-rubric.md and assessor-case-reference.md. Confirm consent/ethics arrangements and pilot the case/method guides. Any changes are versioned before study collection. Fix one Git commit as the study source.
3. Recruit independent participants across the manuscript's competence areas. Start with its proposed minimum six; the eight-row schedule allows a balanced eight-person completion. Six participants give imperfect four-order balance, which must be reported. Continue if new critical omissions persist.
4. Give each participant only their case, assigned method guide, neutral task sheet, and response form. Record task start/end, requests, unfinished tasks, and debrief. There is no empirically justified fixed time limit yet; decide it during pilot and use consistently.
5. Use independent-reconstruction.md for one modeler who did not author the model. Participant packet must exclude author models, destinations, reference answers, and assessor files. Record assistance.
6. Enter actual results in the provided forms. Empty forms remain pending; automation never replaces them with success. Run scripts/reproduce.sh and scripts/summarize_human_results.py. Send the completed forms and anonymized artifacts back for analysis and manuscript integration.

Recruitment/messages have not been sent. No participant names need to be committed publicly; use codes and separate restricted consent records. Synthetic-vignette results support artificial comparative task performance only.
